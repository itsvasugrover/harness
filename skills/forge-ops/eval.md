# forge-ops golden evals (Bet 4 — CI runs these like unit tests)

1. `list-issues` — given a repo with 3 open issues, returns all 3 grouped by label.
2. `open-pr-flow` — given a branch with one commit, opens a PR with the repo template body.
3. `blocked-merge` — given a PR with failing checks, refuses to merge and quotes the blocker.
